The old <code>tools</code> config is still supported for backwards compatibility.</p>\n<hr />\n<h2 id=\"actions\">Actions</h2>\n<p>Each permission rule resolves to one of:</p>\n<ul>\n<li><code>\"allow\"</code> — run without approval</li>\n<li><code>\"ask\"</code> — prompt for approval</li>\n<li><code>\"deny\"</code> — block the action</li>\n</ul>\n<hr />\n<h2 id=\"auto-mode\">Auto mode</h2>\n<p>Start OpenCode with <code>--auto</code> to automatically approve permission requests that are not explicitly denied.</p>\n<pre><code class=\"language-bash\">opencode --auto\n</code></pre>\n<p>You can also use auto mode with <a href=\"cli.html#run\"><code>opencode run</code></a>.</p>\n<pre><code class=\"language-bash\">opencode run --auto &quot;Refactor this module&quot;\n</code></pre>\n<p>Explicit <code>\"deny\"</code> rules are still enforced. Auto mode only changes requests that would otherwise ask for approval.</p>\n<p>In the TUI, open the command palette and select <strong>Enable auto-approve permissions</strong> or <strong>Disable auto-approve permissions</strong> to change modes. When auto mode is active, the prompt displays a muted <code>auto</code> indicator next to the current agent.</p>\n<hr />\n<h2 id=\"configuration\">Configuration</h2>\n<p>You can set permissions globally (with <code>*</code>), and override specific tools.</p>\n<pre><code class=\"language-json\">{\n  &quot;$schema&quot;: &quot;https://opencode.ai/config.json&quot;,\n  &quot;permission&quot;: {\n    &quot;*&quot;: &quot;ask&quot;,\n    &quot;bash&quot;: &quot;allow&quot;,\n    &quot;edit&quot;: &quot;deny&quot;\n  }\n}\n</code></pre>\n<p>You can also set all permissions at once:</p>\n<pre><code class=\"language-json\">{\n  &quot;$schema&quot;: &quot;https://opencode.ai/config.json&quot;,\n  &quot;permission&quot;: &quot;allow&quot;\n}\n</code></pre>\n<hr />\n<h2 id=\"granular-rules-object-syntax\">Granular Rules (Object Syntax)</h2>\n<p>For most permissions, you can use an object to apply different actions based on the tool input.</p>\n<pre><code class=\"language-json\">{\n  &quot;$schema&quot;: &quot;https://opencode.ai/config.json&quot;,\n  &quot;permission&quot;: {\n    &quot;bash&quot;: {\n      &quot;*&quot;: &quot;ask&quot;,\n      &quot;git *&quot;: &quot;allow&quot;,\n      &quot;npm *&quot;: &quot;allow&quot;,\n      &quot;rm *&quot;: &quot;deny&quot;,\n      &quot;grep *&quot;: &quot;allow&quot;\n    },\n    &quot;edit&quot;: {\n      &quot;*&quot;: &quot;deny&quot;,\n      &quot;packages/web/src/content/docs/*.mdx&quot;: &quot;allow&quot;\n    }\n  }\n}\n</code></pre>\n<p>Rules are evaluated by pattern match, with the <strong>last matching rule winning</strong>. <code>\"allow\"</code>.</li>\n<li><code>doom_loop</code> and <code>external_directory</code> default to <code>\"ask\"</code>.</li>\n<li><code>read</code> is <code>\"allow\"</code>, but request</li>\n<li><code>always</code> — approve future requests matching the suggested patterns (for the rest of the current OpenCode session)</li>\n<li><code>reject</code> — deny the request</li>\n</ul>\n<p>The set of patterns that <code>always</code> would approve is provided by the tool (for example, bash approvals typically whitelist a safe command prefix like <code>git
