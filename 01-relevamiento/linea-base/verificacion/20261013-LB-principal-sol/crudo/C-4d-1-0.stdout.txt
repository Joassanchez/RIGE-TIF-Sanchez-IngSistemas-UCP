When auto mode is active, the prompt displays a muted <code>auto</code> indicator next to the current agent.</p>\n<hr />\n<h2 id=\"configuration\">Configuration</h2>\n<p>You can set permissions globally (with <code>*</code>), and override specific tools.</p>\n<pre><code class=\"language-json\">{\n  &quot;$schema&quot;: &quot;https://opencode.ai/config.json&quot;,\n  &quot;permission&quot;: {\n    &quot;*&quot;: &quot;ask&quot;,\n    &quot;bash&quot;: &quot;allow&quot;,\n    &quot;edit&quot;: &quot;deny&quot;\n  }\n}\n</code></pre>\n<p>You can also set all permissions at once:</p>\n<pre><code class=\"language-json\">{\n  &quot;$schema&quot;: &quot;https://opencode.ai/config.json&quot;,\n  &quot;permission&quot;: &quot;allow&quot;\n}\n</code></pre>\n<hr />\n<h2 id=\"granular-rules-object-syntax\">Granular Rules (Object Syntax)</h2>\n<p>For most permissions, you can use an object to apply different actions based on the tool input.</p>\n<pre><code class=\"language-json\">{\n  &quot;$schema&quot;: &quot;https://opencode.ai/config.json&quot;,\n  &quot;permission&quot;: {\n    &quot;bash&quot;: {\n      &quot;*&quot;: &quot;ask&quot;,\n      &quot;git *&quot;: &quot;allow&quot;,\n      &quot;npm *&quot;: &quot;allow&quot;,\n      &quot;rm *&quot;: &quot;deny&quot;,\n      &quot;grep *&quot;: &quot;allow&quot;\n    },\n    &quot;edit&quot;: {\n      &quot;*&quot;: &quot;deny&quot;,\n      &quot;packages/web/src/content/docs/*.mdx&quot;: &quot;allow&quot;\n    }\n  }\n}\n</code></pre>\n<p>Rules are evaluated by pattern match, with the <strong>last matching rule winning</strong>. A common pattern is to put the catch-all <code>\"*\"</code> rule first, and more specific rules after it.</p>\n<h3 id=\"wildcards\">Wildcards</h3>\n<p>Permission patterns use simple wildcard matching:</p>\n<ul>\n<li><code>*</code> matches zero or more of any character</li>\n<li><code>?</code> matches exactly one character</li>\n<li>All other characters match literally</li>\n</ul>\n<h3 id=\"home-directory-expansion\">Home Directory Expansion</h3>\n<p>You can use <code>~</code> or <code>$HOME</code> at the start of a pattern to reference your home directory.
