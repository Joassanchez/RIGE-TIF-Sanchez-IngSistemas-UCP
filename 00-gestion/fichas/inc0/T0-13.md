**§3 Requisitos previos.**

**§4 Instalación.** `git clone <repositorio>`, `cd <carpeta>/src` y `bun install --frozen-lockfile`. El usuario normal no necesita aislar el entorno: eliminá los bloques de aislamiento actuales.

**§5 Configuración.**
- Copia de `rige.env.example` a `rige.env` en las dos plataformas (`cp` y `Copy-Item`), opcional: sin `rige.env` rigen los valores por defecto.
- Tabla de las dos variables:
  - `RIGE_PUERTO`: entero de 1 a 65535; por defecto 4747.
  - `RIGE_ALMACEN`: **directorio** del almacén, no el archivo de la base. Vacío equivale a `%LOCALAPPDATA%\rige` en Windows y a `$XDG_DATA_HOME/rige` o `~/.local/share/rige` en Ubuntu.
- Prelación: variable de entorno → `rige.env` → valor por defecto.
- `rige.env` solo admite esas dos claves; cualquier otra da `configuracion-invalida`. No es un archivo `.env` y Bun no lo carga solo.

**§6 Ejecución y verificación.** En este orden, con lo que se espera ver en cada paso:
1. `bun run esquema`: crea o verifica el esquema y escribe en la salida una línea JSON con `esquema`, `versionRige` (`0.1.0`) y `almacen.ruta` / `almacen.versionEsquema` (1). Repetirlo no cambia nada.
2. `bun run servir`: escribe `{"esquema":1,"direccion":"http://127.0.0.1:4747"}` y queda escuchando. En el navegador, `http://127.0.0.1:4747` muestra «RIGE 0.1.0», la ruta del almacén y la versión de su esquema. Se detiene con Ctrl+C.
3. `bun run verificar` (tipos y construcción, salida 0) y `bun test` (todas pasan).

Además:
- Errores frecuentes: sin `bun run esquema` previo, `servir` termina con `almacen-sin-esquema` (código 1); puerto ocupado → `puerto-ocupado` (código 1): cambiar `RIGE_PUERTO`.
- Para invocar la CLI directamente: `bun --silent run rige -- esquema`. Sin `--silent`, `bun run` agrega su propia línea `$ bun …` al canal de error (comprobado el 30/09/2026).
- Tabla del contrato de salida aplicable al v1: 0 respuesta válida (JSON en la salida); 1 error de uso (JSON de error en el canal de error, códigos `almacen-sin-esquema`, `configuracion-invalida`, `puerto-ocupado`); 2 argumentos inválidos (`argumentos-invalidos`); 70 falla interna (`interno`; `--depurar` agrega el stack, sin logs a disco). Forma del error: `{"esquema":1,"error":{"codigo":"…","mensaje":"…"}}`. Las filas de RF-05 (código 3) y RF-08 no se documentan todavía: llegan con los subcomandos de resolución.
