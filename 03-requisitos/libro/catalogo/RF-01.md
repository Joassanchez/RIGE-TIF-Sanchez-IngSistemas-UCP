# RF-01

| Campo | Valor |
|---|---|
| ID | RF-01 |
| Enunciado | Dado un agente, RIGE informa el valor efectivo de cada una de sus claves o de la clave solicitada, la declaración que lo determina con su entrada, archivo y posición, y las declaraciones desplazadas |
| Tipo | Funcional |
| Categoría (si es no funcional) | — |
| Prioridad | Must |
| Motivo de la prioridad | La referente identifica como aporte más directo el archivo que determina cada valor vigente (Anexo VI, A.VI.5). De esta capacidad dependen las demás consultas y el recorrido del prototipo v1. |
| Criterio de aceptación | CA-1: Dado un escenario del entorno controlado con una clave declarada en tres entradas de distinta precedencia, al consultar esa clave para un agente el sistema informa el valor de la entrada de mayor precedencia. Identifica su archivo y su línea, y lista las dos restantes como desplazadas. El valor coincide con la salida del comando nativo de resolución por agente. CA-2: Consultado el mismo agente sin indicar clave, el sistema informa el valor efectivo de cada una de sus claves, cada uno con la misma procedencia y las mismas declaraciones desplazadas que en la consulta por clave. Para los valores incorporados por sustitución, ambas consultas presentan el origen y la condición de definido, con el contenido excluido según RNF-04. |
| Trazabilidad | H-01, H-02, H-06, HA-2 y HA-5; aporte de la referente (Anexo VI, A.VI.5). Validado (redacción del 26/09); precisión del 24/10 pendiente de revalidación (R-11) |
| Estado de validación | Validado |
| Iteración prevista | 1 |
| ¿Integra el MVP? | Sí |
