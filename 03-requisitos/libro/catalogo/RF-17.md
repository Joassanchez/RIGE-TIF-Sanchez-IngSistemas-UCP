# RF-17

| Campo | Valor |
|---|---|
| ID | RF-17 |
| Enunciado | RIGE conserva cada resolución de un proyecto con su fecha y el resumen de las entradas leídas, y permite recuperarla |
| Tipo | Funcional |
| Categoría (si es no funcional) | — |
| Prioridad | Must |
| Motivo de la prioridad | Sostiene la estación de persistencia del caso vertical del prototipo v1 y permite identificar sobre qué estado de las entradas se resolvió (E-02) |
| Criterio de aceptación | CA-1: Resuelto un proyecto del entorno controlado, la resolución queda guardada en el almacén propio con su fecha, y su recuperación devuelve los mismos valores, procedencias y declaraciones desplazadas que la consulta que la produjo. CA-2: Cada resolución declara el resumen del conjunto de entradas leídas; modificado el contenido de una entrada, una nueva resolución del mismo proyecto declara un resumen distinto. CA-3: El almacén conserva las últimas 20 resoluciones de cada proyecto |
| Trazabilidad | Acta del 26/09/2026, E-02; ADR-023; ADR-061; ADR-073; acta de validación, extensión |
| Estado de validación | Validado |
| Iteración prevista | 1 |
| ¿Integra el MVP? | Sí |
