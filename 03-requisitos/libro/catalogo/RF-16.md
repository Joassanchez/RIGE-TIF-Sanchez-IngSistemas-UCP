# RF-16

| Campo | Valor |
|---|---|
| ID | RF-16 |
| Enunciado | RIGE lista los agentes del proyecto, declarados por el usuario e incorporados por la herramienta, e identifica cada uno como tal, por ambas interfaces |
| Tipo | Funcional |
| Categoría (si es no funcional) | — |
| Prioridad | Must |
| Motivo de la prioridad | Toda consulta parte de un agente determinado, y los agentes que la herramienta incorpora sin declaración son los que el usuario puede desconocer, conforme al apartado I.6.1 del informe de la AE1. Sin listado, el agente externo debe conocer de antemano el nombre que consulta |
| Criterio de aceptación | CA-1: Dado un escenario con agentes declarados y agentes que la herramienta incorpora sin declaración, el sistema lista todos e identifica cada uno como declarado o nativo. CA-2: El conjunto coincide con los agentes que reconoce OpenCode 1.18.25 según el comando nativo `opencode agent list` de la versión 1.18.25. CA-3: La línea de comandos y la interfaz web local informan el mismo conjunto |
| Trazabilidad | H-18; AE1, I.6.1 e I.1.3; revisión parcial de la decisión L-06 (ADR-059), pendiente de convalidación; ADR-060 (dato del CA-2) |
| Estado de validación | Pendiente |
| Iteración prevista | 2 |
| ¿Integra el MVP? | Sí |
