# RF-10

| Campo | Valor |
|---|---|
| ID | RF-10 |
| Enunciado | RIGE informa, junto con la decisión de permiso, si la herramienta queda disponible para el modelo o si la configuración la retira por completo |
| Tipo | Funcional |
| Categoría (si es no funcional) | — |
| Prioridad | Should |
| Motivo de la prioridad | La decisión por sí sola no describe el efecto: una denegación general retira la herramienta y una excepción posterior vuelve a exponerla íntegra. Se prioriza como Should porque extiende la consulta de permiso sin intervenir en la medición final ni en la mitigación del riesgo principal |
| Criterio de aceptación | CA-1: Dado un agente con una denegación de patrón general sobre una herramienta, el sistema informa que la herramienta no se ofrece al modelo. CA-2: Agregada una excepción posterior sobre el mismo tipo, informa que vuelve a estar disponible. CA-3: Ambos resultados coinciden con la lista de herramientas que el código de OpenCode 1.18.25 ofrece al modelo para ese agente tras aplicar sus permisos, obtenida sin ejecutar un modelo |
| Trazabilidad | H-08; (Anexo III, D-58, CA-3) |
| Estado de validación | Validado |
| Iteración prevista | 3 (condicionado a las horas) |
| ¿Integra el MVP? | No |
