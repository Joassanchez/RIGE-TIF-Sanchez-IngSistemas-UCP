# RF-10

| Campo | Valor |
|---|---|
| ID | RF-10 |
| Enunciado | RIGE informa, junto con la decisión de permiso, si la herramienta queda disponible para el modelo o si la configuración la retira por completo |
| Tipo | Funcional |
| Categoría (si es no funcional) | — |
| Prioridad | Should |
| Motivo de la prioridad | La decisión por sí sola no describe el efecto: una denegación general retira la herramienta y una excepción posterior vuelve a exponerla íntegra. Se prioriza como Should porque extiende la consulta de permiso sin intervenir en la medición final ni en la mitigación del riesgo principal |
| Criterio de aceptación | CA-1: Dado un agente con una denegación de patrón general sobre una herramienta, el sistema informa que la herramienta no se ofrece al modelo. CA-2: Agregada una excepción posterior sobre el mismo tipo, informa que vuelve a estar disponible. CA-3: Ambos resultados coinciden con el conjunto de herramientas que la herramienta ofrece en ejecución |
| Trazabilidad | H-08 |
| Estado de validación | Validado |
| Iteración prevista | Sin asignar |
| ¿Integra el MVP? | No |
