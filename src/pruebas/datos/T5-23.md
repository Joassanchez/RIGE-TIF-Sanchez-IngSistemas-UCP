## Precedencia de argumentos

La ayuda y la versión se resuelven antes del parseo completo; los formatos excluyentes se rechazan primero. Ninguna fila requiere ensamblado.

| argv | Formato | Canal | Código | Ensamblado |
|---|---|---|---|---|
| vacío, pipe | JSON de error heredado único | stderr | 2 | no |
| vacío, consola | ayuda texto | stderr | 2 | no |
| `--help --invalida` | ayuda texto | stdout | 0 | no |
| `valores --help --invalida` | ayuda específica texto | stdout | 0 | no |
| `--texto --desconocida` | error texto y sugerencia | stderr | 2 | no |
| `--json --texto` | error JSON | stderr | 2 | no |
| `otro`, pipe | error JSON heredado | stderr | 2 | no |
| `--version`, pipe | texto | stdout | 0 | no |
| `--version --json` | JSON propio de versión | stdout | 0 | no |

Excepciones nuevas a L-2: omisión de proyecto, ayuda/versión y estado. Los mensajes heredados solo cambian donde afirmaban que proyecto era obligatorio.
